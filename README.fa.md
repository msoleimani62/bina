## وضعیت فعلی

✅ **MVP کامل شد (فازهای ۰ تا ۵).** هسته‌ی مرکزی، لایه‌ی ترجمه، هر پنج
کامپوننت کاربری، و خط‌لوله‌ی زمان‌بند+تحویل، سرتاسر ساخته و تست شدن: فیدها
با ریتم خودشون ingest می‌شن، صرف‌نظر از اینکه کسی چت رو باز کرده باشه یا نه؛
هر خبر فقط یک‌بار به‌ازای هر زبان ترجمه و کش می‌شه؛ و به‌صورت پیام عکس‌دار یا
متنی (همراه با دکمه‌ی ذخیره) به هر مشترک واجدشرایط تحویل داده می‌شه، با
جلوگیری کامل از تکرار تحویل برای هر کاربر. مرحله‌ی بعدی رو در
[`ROADMAP.md`](ROADMAP.md) ببینید (به‌روزرسانی خودکار، کشف فید غنی‌تر،
صیقل‌دادن بسته‌بندی).

## قابلیت‌ها

- افزودن هر فید RSS دلخواه با `/addfeed`؛ فیدهای جدید قبل از ورود به استخر
  مشترک یک دوره‌ی آزمایشی (probation) رو طی می‌کنن که فقط برای خودِ
  اضافه‌کننده ارسال می‌شه.
- اشتراک بر اساس دسته‌بندی (تکنولوژی، اخبار عمومی، هنر، یا هر دسته‌ی
  دیگه‌ای که اضافه کنید) از طریق `/categories`.
- ترجمه‌ی خودکار به زبانی که در `/settings` انتخاب می‌کنید، با کش‌شدن
  نتیجه تا یک خبر هرگز برای یک زبان دوبار ترجمه نشه، صرف‌نظر از تعداد
  کاربرانی که اون زبان رو مشترکن.
- امکان بی‌صداکردن یک فید خاص حتی داخل دسته‌ای که دنبال می‌کنید، از طریق
  `/mutefeeds`.
- ذخیره‌ی خبر برای بعداً با دکمه‌ی ⭐، با وضعیت خوانده/نخوانده و حذف
  تک‌ضربه‌ای از طریق `/saved`.
- نمایش تصویر خبر در کنار متن ترجمه‌شده در صورت وجود، با fallback خودکار
  به پیام متنی اگر تلگرام نتونه عکس رو دریافت کنه.
- رابط کاربری و مستندات کاملاً دوزبانه (فارسی/انگلیسی)، با سیستم زبانی که
  افزودن زبان‌های بیشتر رو در چند دقیقه ممکن می‌کنه.
- دیتابیس مشترک و مرکزی برای فیدها: یک چرخه‌ی زمان‌بند به همه‌ی کاربران
  سرویس می‌ده، پس خبر حتی اگر چند روز هیچ‌کس بات رو باز نکنه، همچنان
  جریان داره.

## معماری

```
bina/
├── core/         # دریافت، حذف تکرار، مدل‌های دیتابیس — بدون هیچ کد تلگرامی
├── bot/          # هندلرهای تلگرام (aiogram) — نازک، فقط مصرف‌کننده‌ی core/
├── components/   # قابلیت‌های افزودنی: mute، save، settings، feed_submission، subscriptions، delivery
├── locales/      # en.json / fa.json — هیچ رشته‌ی رابط‌کاربری‌ای جای دیگه نوشته نمی‌شه
tests/            # تست‌های واحد + یکپارچگی
deploy/           # قالب سرویس systemd
```

قوانین طراحی (فهرست کامل در [`CONTRIBUTING.md`](CONTRIBUTING.md)):

- `core/` هرگز `aiogram` را import نمی‌کند — کاملاً مستقل از فریم‌ورک
  می‌ماند.
- هر قابلیت جدید کاربری یک پوشه‌ی جدید زیر `components/` است، که با حذف
  پوشه‌اش و یک خط ثبت‌نامش، کاملاً قابل‌حذف است.
- هیچ رشته‌ی رابط‌کاربری خارج از `locales/*.json` مجاز نیست.

برای معماری کامل و الزامات مهندسی که این پروژه بر اساس آن ساخته شده،
[`AI_BUILD_PROMPT.md`](AI_BUILD_PROMPT.md) را ببینید، و برای برنامه‌ی
ساخت فازبندی‌شده، [`ROADMAP.md`](ROADMAP.md) را.

## نصب

نیازمند **پایتون ۳.۱۱ یا بالاتر**.

```bash
git clone https://github.com/msoleimani62/bina.git
cd bina
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
# فایل .env را ویرایش کنید و BINA_BOT_TOKEN و BINA_TRANSLATE_API_KEY را وارد کنید
bina-bot install
```

`bina-bot install` فقط نسخه‌ی پایتون را بررسی و تأیید می‌کند — خودش چیزی
نصب نمی‌کند؛ `pip install -e ".[dev]"` در مرحله‌ی قبل قبلاً تمام
وابستگی‌ها را نصب کرده است.

## تنظیمات

تمام تنظیمات از متغیرهای محیطی خوانده می‌شود (فایل `.env` به‌طور خودکار
بارگذاری می‌شود). `.env.example` را به `.env` کپی کنید و مقادیر زیر را
پر کنید:

| متغیر | الزامی | توضیح |
|---|---|---|
| `BINA_BOT_TOKEN` | بله | توکن بات تلگرام از [@BotFather](https://t.me/BotFather). |
| `BINA_TRANSLATE_API_KEY` | بله | کلید API سرویس Google Cloud Translation نسخه‌ی ۲. |
| `BINA_DATABASE_URL` | خیر | آدرس async سازگار با SQLAlchemy. پیش‌فرض: فایل محلی `sqlite+aiosqlite:///bina.db`. |

## اجرا

```bash
bina-bot run
```

این دستور در اجرای اول جدول‌های دیتابیس را می‌سازد و بات را در حالت
polling اجرا می‌کند، درحالی‌که زمان‌بند در پس‌زمینه با چرخه‌ی ۱۵ دقیقه‌ای
اجرا می‌شود.

برای اجرای دائمی روی یک سیستم لینوکسی مبتنی بر systemd،
[`deploy/bina-bot.service`](deploy/bina-bot.service) را ببینید — آن را
در `/etc/systemd/system/` کپی کنید، مسیرهای داخلش را تنظیم کنید، سپس:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now bina-bot.service
```

## دستورات بات (راهنمای استفاده)

| دستور / اقدام | کاری که انجام می‌دهد |
|---|---|
| `/start` | اولین برخورد — شما را ثبت‌نام می‌کند و زبان رابط کاربری را از تلگرام تشخیص می‌دهد. |
| `/categories` | اشتراک/لغو اشتراک دسته‌بندی‌های خبری با یک ضربه. |
| `/mutefeeds` | بی‌صدا یا فعال‌کردن فیدهای خاص، حتی داخل دسته‌ای که مشترک آن هستید. |
| `/addfeed <آدرس> [دسته‌بندی]` | افزودن فید RSS/Atom شخصی خودتان. تا وقتی فعالیت کافی داشته باشد و به استخر مشترک ترفیع پیدا کند، فقط برای خودتان probation است. |
| `/settings` | تغییر زبان ترجمه و دسترسی سریع به دسته‌بندی‌ها/بی‌صداها/ذخیره‌شده‌ها. |
| `/saved` | فهرست خبرهای ذخیره‌شده‌ی شما، با دکمه‌های خوانده‌شده و حذف. |
| دکمه‌ی ⭐ روی هر خبر تحویلی | ذخیره‌ی همان خبر برای بعداً. |


## حذف نصب

```bash
# اگر سرویس systemd راه‌اندازی کرده‌اید، ابتدا آن را متوقف کنید
sudo systemctl disable --now bina-bot.service
sudo rm /etc/systemd/system/bina-bot.service

# حذف پکیج و محیط مجازی
deactivate 2>/dev/null || true
rm -rf .venv

# حذف دیتابیس محلی و فایل تنظیمات (این کار تمام داده‌های ذخیره‌شده را پاک می‌کند)
rm -f bina.db .env

# در نهایت، حذف خودِ پوشه‌ی پروژه
cd .. && rm -rf bina
```

اگر بینا را به‌صورت سراسری (system-wide) و نه در یک محیط مجازی نصب
کرده‌اید، پیش از حذف پوشه، دستور `pip uninstall bina` را اجرا کنید.
