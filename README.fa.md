> به زبان دلخواه هر کاربر ترجمه می‌کند.

## وضعیت فعلی

✅ **MVP کامل شد (فازهای ۰ تا ۵).** هسته‌ی مرکزی، لایه‌ی ترجمه، هر پنج
کامپوننت کاربری، و خط‌لوله‌ی زمان‌بند+تحویل، سرتاسر ساخته و تست شدن: فیدها
با ریتم خودشون ingest می‌شن، صرف‌نظر از اینکه کسی چت رو باز کرده باشه یا نه؛
هر خبر فقط یک‌بار به‌ازای هر زبان ترجمه و کش می‌شه؛ و به‌صورت پیام عکس‌دار یا
متنی (همراه با دکمه‌ی ذخیره) به هر مشترک واجدشرایط تحویل داده می‌شه، با
جلوگیری کامل از تکرار تحویل برای هر کاربر. مرحله‌ی بعدی رو در
[`ROADMAP.md`](ROADMAP.md) ببینید (به‌روزرسانی خودکار، کشف فید غنی‌تر،
صیقل‌دادن بسته‌بندی).

## قابلیت‌ها (برنامه‌ریزی‌شده)

- افزودن هر فید RSS دلخواه؛ فیدهای جدید قبل از ورود به استخر مشترک یک دوره‌ی
  آزمایشی (probation) رو طی می‌کنن.
- اشتراک بر اساس دسته‌بندی (تکنولوژی، اخبار عمومی، هنر، یا هر دسته‌ی دیگه‌ای
  که اضافه کنید).
- ترجمه‌ی خودکار به زبان انتخابی شما، با کش‌شدن نتیجه تا یک خبر هرگز برای یک
  زبان دوبار ترجمه نشه.
- امکان بی‌صداکردن یک فید خاص حتی داخل دسته‌ای که دنبال می‌کنید.
- ذخیره‌ی خبر برای بعداً، با وضعیت خوانده/نخوانده و حذف تک‌ضربه‌ای.
- نمایش تصویر خبر در کنار متن ترجمه‌شده، در صورت وجود.
- رابط کاربری و مستندات کاملاً دوزبانه (فارسی/انگلیسی)، با سیستم زبانی که
  برای افزودن زبان‌های بیشتر طراحی شده.

## معماری

```
bina/
├── core/         # دریافت، حذف تکرار، مدل‌های دیتابیس — بدون هیچ کد تلگرامی
├── bot/          # هندلرهای تلگرام (aiogram) — لایه‌ی نازک، فقط مصرف‌کننده‌ی core/
├── components/   # قابلیت‌های افزودنی: mute، save، settings، feed_submission
├── locales/      # en.json / fa.json — هیچ رشته‌ی ثابت رابط کاربری جای دیگه‌ای نیست
tests/            # تست‌های واحد و یکپارچگی
deploy/           # قالب سرویس systemd
```

برای معماری کامل و نیازمندی‌های مهندسی، به
[`AI_BUILD_PROMPT.md`](AI_BUILD_PROMPT.md) مراجعه کنید.

## نصب

```bash
git clone https://github.com/msoleimani62/bina.git
cd bina
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
# فایل .env را ویرایش کرده و BINA_BOT_TOKEN و BINA_TRANSLATE_API_KEY را وارد کنید
bina-bot install
```

## اجرا

```bash
bina-bot run
```

برای اجرای دائمی روی یک سیستم لینوکسی مبتنی بر systemd، به
[`deploy/bina-bot.service`](deploy/bina-bot.service) مراجعه کنید.
